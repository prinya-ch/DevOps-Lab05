# เกมต่อภาพ Jigsaw

เกมต่อภาพสำหรับ Browser บน PC สร้างด้วย HTML, CSS และ JavaScript โดยใช้ `car.jpg` แบ่งเป็นจิ๊กซอว์ 20 ชิ้น

บนหน้าจอ Desktop กระดานและถาดชิ้นส่วนจะแสดงเคียงกัน โดยย่อชิ้นส่วนในถาดให้เห็นครบโดยไม่ต้องเลื่อนหน้า

## วิธีเล่น

1. เปิด `index.html` ด้วย Browser
2. ลากชิ้นส่วนจากถาดไปวางบนตำแหน่งที่ตรงกันบนกระดาน
3. ใช้ปุ่ม **ดูภาพตัวอย่าง** เพื่อแสดงภาพจาง ๆ บนกระดาน และกด **เริ่มใหม่** เพื่อสุ่มเกมใหม่
4. เกมพยายามเปิดเพลงพื้นหลังจาก `themesong.mp3` อัตโนมัติ และมีปุ่มเปิด/ปิดเพลง
5. หาก Browser บล็อกการเล่นเพลงอัตโนมัติ ให้คลิก **เปิดเพลงพื้นหลัง**
6. เกมมีเสียงเมื่อหยิบชิ้นส่วน วางถูกตำแหน่ง หรือวางไม่ตรงตำแหน่ง

ต้องวางไฟล์ `car.jpg`, `index.html`, `style.css` และ `script.js` ไว้ในโฟลเดอร์เดียวกัน
